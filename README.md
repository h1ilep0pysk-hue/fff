🤖 Telegram AI Assistant Bot
Бот для генерации креативного контента с поддержкой нескольких AI-моделей через OpenRouter API.

📁 Структура проекта
main.py - Основной файл запуска
Инициализирует приложение Telegram бота

Регистрирует все обработчики команд и сообщений

Запускает бота в режиме polling

Регистрируемые обработчики:

/start, /help - основные команды

/idea, /title, /hashtag, /image - AI-команды

/change_ai, /return_ai - переключение между нейросетями

/model - выбор модели ИИ

Обработка текстовых сообщений (чат)

config.py - Конфигурация
Token - токен Telegram бота

OPENROUTER_API_KEY - API-ключ для OpenRouter

DEFAULT_MODELS - словарь доступных моделей по умолчанию

user_models - словарь для хранения выбранных моделей пользователей

handlers/basic_commands.py - Базовые команды
start() - приветственное сообщение

info() - информация о доступных командах

handlers/ai_commands.py - AI-команды для генерации контента
Функции:

idea() - генерация идей для видео по теме

title() - создание цепляющих заголовков

hashtag() - подбор популярных хештегов

image() - анализ изображений (описание содержимого)

Особенности:

Использует асинхронные операции для неблокирующего выполнения

Визуальная индикация загрузки (анимация точек)

Автоматическое переключение между двумя нейросетями в зависимости от чата

Очистка текста от Markdown-символов

Ограничение длины сообщений (4000 символов)

handlers/chat_handler.py - Обработчик обычных сообщений
Обрабатывает все текстовые сообщения, не являющиеся командами

Использует выбранную пользователем модель ИИ

Поддерживает два режима:

Стандартный: DeepSeek R1T2 Chimera

Альтернативный: Kwaipilot Kat-Coder-Pro

Интерактивная анимация загрузки

handlers/ai_switch.py - Переключение между нейросетями
change_bot() - переключение на альтернативную нейросеть

return_bot() - возврат к стандартной нейросети

Сохраняет ID чата в bot_data для определения активной нейросети

handlers/model_selector.py - Система выбора моделей ИИ
Основные функции:

model() - отображение меню выбора модели

model_callback() - обработка выбора конкретной модели

use_model_callback() - активация выбранной модели

choose_another_callback() - возврат к выбору модели

settings_callback() - настройки модели

back_to_model_callback() - возврат к главному меню

Поддерживаемые модели:

🤖 GPT-3.5 Turbo

🚀 GPT-4

🧠 Claude 3

⭐ Kwaipilot

🚀 Установка и запуск
Установите зависимости:

bash
pip install python-telegram-bot openai
Настройте конфигурацию в config.py:

Получите токен бота у @BotFather

Получите API-ключ на OpenRouter

Запустите бота:

bash
python main.py
🎯 Основные команды
Команда	Описание
/start	Запуск бота
/help	Список команд
/idea [тема]	Идея для поста/видео
/title [тема]	Цепляющие заголовки
/hashtag [тема]	Популярные хештеги
/image [url]	Анализ изображения
/model	Выбор модели ИИ
/change_ai	Переключить нейросеть
/return_ai	Вернуть стандартную нейросеть
🔧 Технические особенности
Асинхронная обработка
Использует asyncio для неблокирующих операций

ThreadPoolExecutor для вызова синхронных API-запросов

Анимация загрузки во время генерации контента

Безопасность
Очистка текста от Markdown-символов

Ограничение длины сообщений для Telegram API

Изоляция пользовательских данных

Модульность
Разделение логики по отдельным файлам

Легкое добавление новых команд и моделей

Гибкая система переключения между AI-провайдерами

📊 Хранение данных
user_models - словарь в памяти для хранения выбранных моделей

bot_data - хранение состояния переключения нейросетей

base.json - временное хранение данных для команд

⚠️ Важные замечания
Бот использует бесплатные модели через OpenRouter

Могут быть ограничения по количеству запросов

Для работы с изображениями требуется URL-адрес

Токены и API-ключи должны быть защищены
